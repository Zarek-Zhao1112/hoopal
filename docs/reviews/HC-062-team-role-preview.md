# HC-062 · 球员角色网页预览独立审查

审查 agent `team_roles_preview_review` 静态检查独立预览的角色映射、体型目录、交换、步骤文案与玻璃面板。主控修复并用 Edge 核对流程。

| 级别 | 触发与影响 | 修复及复验 |
| --- | --- | --- |
| P2 | 低位分切的步骤讲解含并列编号和省略「号」的编号，原先只替换完整编号。站位卡悬停提示也可能仍用模板编号，读到的号码和球场不同。 | 步骤与站位职责共用号码转换，保留 D1 等对手标记。Edge 验证低位分切第 7 步实际显示示例球衣号码。 |
| P3 | 训练说明超过两行时，手机无法通过悬停读全文。 | 增加「讲解」玻璃面板。Edge 在模拟手机尺寸打开并读取全文。 |

审查未发现体型过滤、棋子身份保留或临时交换的其他阻断。范围限网页设计预览，未做 APK 或物理设备验收。

原型更新后，同一审查 agent 复核了内联选项、当前球队草稿和保存行为、同人数体型筛选，以及 9 套 4v4 进攻战术的四人位置偏好。重复角色仍由不同球员占据各自的位置，未发现阻断。此轮独立复审限静态代码与战术数据。

细分 4v4 角色后，审查 agent 再次逐套核对 9 套模板及两种人数的选项。高低位的两名接球策应、双掩护和西班牙挡拆各两名掩护配合均对应模板职责。主控在 Edge 用高低位复验重复角色的分配。
