## HC-005-R1 · P2 · 多换行讲解被裁切

状态：`verified`。发现：interaction_design；修复：engine；浏览器复验：主 agent。

触发：合法笔记包含大量换行，如 `('逐行讲解\n').repeat(80)`。初版只按 160 / 90 码点分页，一页可包含 33 / 19 行，而 `#note-preview` 使用 `overflow:hidden`。显示不下的下半部分被裁掉，翻下一页又跳过了这些文字。

修复：对话框打开后，在真实正文区域二分测量每页可容纳的前缀，以 `scrollHeight <= clientHeight` 确定边界，保留换行和 Unicode 码点。旋转后按先前字符偏移重新分页定位。页码与关闭按钮固定，不要求内部滚动。

复验：独立 reviewer 复核算法的前进性、字符保留及旋转定位逻辑。主 agent 在 360×640 与 844×390 的真实 Chrome 中加载 2000 个 UTF-16 单元的笔记，含 280 行编号、篮球 emoji 及空行；逐页核对正文没有溢出，所有页拼接严格还原原文。打开讲解后旋转仍包含原阅读位置。通过。

## HC-005-R2 · P2 · 平板卡片分类徽标被裁切

状态：`verified`。发现与复验：主 agent；修复：ui。

触发：1024×768 平板横屏侧栏，固定高度卡片同时显示编号、名称、说明、徽标，累计高度超过卡片，徽标底部被裁。

修复：隐藏装饰编号；卡片改为纵向 flex，说明可收缩，徽标不收缩并固定在卡片内底部，保留原分页高度。

复验：截图检查与六种屏幕的浏览器边界检查通过，新增对可见徽标相对卡片边界的断言。
