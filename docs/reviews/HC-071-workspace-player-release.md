# HC-071 · 三页排版与单人编辑审查

独立只读审查覆盖柜位选中、编辑隔离、草稿、档案版本和两套外观的主页面布局。单人编辑按当前球衣的球员 ID 锁定，编辑面板不能切人。提交复用整队号码校验与存储版本保护。

审查发现，`frontend/src/lineups/wizard/drafts.js` 在旧整队草稿和新单人保存都修改同一字段时，更新整队草稿版本会让旧值可能覆盖新值。已在合并前检查同一字段的分歧。有冲突时保留草稿的原版本，提交仍受版本检查保护。主控用两个样例核对冲突草稿保留原版本、无冲突草稿吸收新保存并保留其他未保存修改。

主页面样式审查覆盖写实、玻璃、短屏和二级路由。短屏和桌面保留各自布局。浏览器与设备结果见 [HC-071](../tasks/HC-071-workspace-player-release.md)。
