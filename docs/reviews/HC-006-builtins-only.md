## 审查证据

- 当前 app 仅引用新 builtins 仓库，不读取旧个人 Play，不调用旧 `saveDraft/saveLibrary`，没有自动归档或个人保存 / 新建 / 导入 / 改名事件。
- 主键只写 `null/[]`，原 WebView 同步清理；残余文件正则锚定旧两键的 corrupt / tmp，原生只枚举 DATA/halfcourt/storage，不递归。新选择键、无关键与外部导出不在删除范围。
- 删除失败逐项累积 warning、`legacyCleared=false`，提示不会被进度写入成功覆盖；没有提前完成标记，下次 load 重试。
- 保存选择只序列化内置 ID / 步骤，原始模板范围约束有效，临时编辑只留内存。
- HTML 的个人入口真正删除；CSS 去掉来源 tabs 后重排库区域，导出仍可用。
