# HC-066 · 双外观网页预览审查

独立审查者静态检查 Vite 注入入口、内存示例数据、主卡背景、控件及响应布局。确认未改正式入口，主题在预览中生效。

- 训练场和我的的切换按钮继承顶部占位区的 `pointer-events: none`。直接点击会穿透。主控恢复按钮命中，Edge 中实际点击两处均切换外观。
- 空队状态隐藏示意柜时会移除栅格占位，导致提示和按钮进入错误行。改为保留占位的隐藏方式，静态核对。
- 短屏把竖图拉得过宽，启动动效也会抓到已透明化的柜位。极短屏改用宽图和对应柜位，预览直接跳过启动动效。主控在 360×400 与 1280×800 截图检查背景和控件。
- 浏览器禁止持久存储时，获取 `localStorage` 也可能抛错。外观偏好读取和写入可降级，业务示例数据仍在内存。

主控另从宽屏截图发现球衣和资料条重叠，缩短资料与操作宽度并将换人控件居中。1280×800 复看，号码、球衣与换人控件各自可见。范围仅为本地网页预览。
