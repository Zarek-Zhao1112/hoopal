# 玻璃更衣室场景

## 目标

HC-083 采用用户确认的 A 版：写实更衣室铺满玻璃更衣室主卡，整体浅蓝冷调，保留暖色吊灯、柜灯及反光。卡片边缘与操作按钮使用半透明玻璃材质，背景轻微柔化，球衣、标题与操作保持清晰。

## 构图与接口

玻璃和写实共用场景画面比例、柜内球衣区域与圆点位置；竖屏使用现有 `locker-portrait.jpg`，横屏与桌面使用 `locker-wide.jpg`。场景视觉层不接收指针、不更改交互 DOM 顺序，整卡滑动继续使用现有组件。底部两个按钮等宽等高。

场景只作用于更衣室主卡及无球队空卡。更衣室读失败画面、编辑面板、训练场与「我的」不使用这层场景。保留现有启动时间线，开场单柜快照在临时画面容器中冻结，避免把整卡模式的独立球衣当作完整柜体。

运行 `node scripts/preview-appearance.mjs` 后，`http://127.0.0.1:4196/?locker=glass-scene` 直接以玻璃外观打开，示例球队只在内存中使用；右上角可对比写实外观。

## 数据与非目标

纯 CSS 变更，不新增存储键或数据迁移，不修改队员、角色与战术逻辑。复用离线图片，不把原型截图当作网页背景，不加入账号或远程服务。

## 验收

竖横屏和桌面无溢出，球衣位于中央柜内，标题与按钮可辨识。所有可见操作可点击，横滑后的编辑仍对应当前队员。两种外观切换可靠，写实版保持原构图与外观。构建、浏览器和设备证据分别记录在 [HC-083](../tasks/HC-083-glass-locker-scene.md)。
