## 目标与边界

- 阵容 / 演练 / 战术库切换，从目标底部导航按钮中心向外柔光揭示新页面，600ms（100ms起势、350ms展开、150ms收尾；此前1.9.0为350ms硬边圆形）；导航始终可见可操作。程序导航可用目标按钮中心。重复当前页不播放，快速换页以最后意图为准，旋转 / 后台 / 弹窗清理过渡。
- 遵守系统减少动态效果设置；Android WebView 96 可运行，不能仅依赖 View Transition API。过渡不复制交互状态或存储、不调用原生截图、不访问网络，不引入整页滚动。
- 如使用旧页视觉快照，必须不可交互、不占布局、不进入读屏 / 焦点，不产生重复 ID / 选择器命中；新页及时可用，异常 / 取消后恢复所有样式与层。
- 本轮去除已在源码完成的「内置战术 · 本地离线演练」常驻文案，真实异常提示继续显示。
- 用户在明确箭头问答中最终选择：**手指从右向左（←）拖动，从 1 号切到 2 号；向右（→）返回**。本次新授权覆盖此前右拖下一位的约定。DOM 柜位改为成员正序，场景随手指移动；索引与球衣号码分别处理，不根据号码大小推断第几位。保持首尾、cancel、纵向拒绝、成员记忆和草稿安全。
- 子页面轻微滑入视实际模块复杂度实现；不对球员柜位再叠加圆形。主要必需验收是三主页面及报告问题。
