# 战术库纵向叠卡

日期：2026-10-23。状态：用户已批准最新标题卡预览，正式接入见[HC-016](../tasks/HC-016-library-title-cards.md)；此前预览与历史方案见[HC-015](../tasks/HC-015-stacked-library-preview.md)。

目标：让内置战术像一叠教练战术卡。沿用蓝灰、雾白、木地板与玻璃导航。手机竖屏整页不滚动。3v3/4v4、进攻/防守保持独立选择。

最新用户确认：默认所有战术都收成标题卡，不预选、不显示球场，不设置统一「展开／收起」按钮。点某张标题仅展开这一张，显示球场示意与演练入口；再点同一张回到全部收起，换另一张则前卡自动收起。卡片顺序保持稳定，切换人数/攻防也回到全部收起。此前整叠封面与统一按钮方案保留在历史预览v1-stack.html，不再作为当前方案。

接入节奏沿用批准预览：整体约400ms、邻卡位移错开约35ms，快速操作以最后意图为准，系统减少动态效果时立即到终态。手机横屏展开时将完整卡与其余标题分区，全部收起时用两列标题，避免缩得不可读。遵守系统减少动态效果设置，后续可根据用户实际体验调整。

预览接口：自包含HTML及内存状态，提供人数/攻防筛选、展开收起、切换卡片和阶段对比；球场为静态构图示意，开始演练仅显示提示。无账号、服务、存储读取写入，无数据迁移，也不替换现有APK。

正式接口：library-deck-state纯函数计算矩形，library-deck组件接受root/makeThumbnail/onPlay，提供render/setBusy/reset/refreshLayout。当前展开ID只在内存；进入库和筛选回到全部收起，同组重绘保持展开。真实缩略图复用既有木地板SVG；只有CTA才调用已有来源解除与载入，成功后自动播放，失败不导航、保留卡供重试。HC-027曾采用6＋3分页，用户随后在HC-028确认一页九卡预览，由HC-029正式接入：九进攻/四防守无分页，常规竖屏单卡横排小球场和说明；短屏覆盖当前卡并显示「收起 · 返回列表」，其他标题隐藏/禁焦点，收回恢复全部。横屏/平板左预览、右其余标题。普通同组重绘保展开，入库及换组全收起；换组旧节点事件失效，加载中锁标题/CTA及收回，失败保展开重试。浏览不改演练或写入存储。桌面库独占页面，播放时不保留旧左侧列表。数据键、Play、阵容与推荐协议均不改，无迁移；WebView96用hidden/disabled/ResizeObserver与减少动效回退。

验收：全部标题收起/点开一张/换卡三张实际浏览器画面，可点击预览；默认无球场且无统一按钮，同卡再点全收、换卡仅一张显示、筛选重置；小屏一屏可见、标题中心可点、人数攻防数量正确、快速点击与减少动态效果收敛，离线无网络请求；独立审查图检。正式接入及设备验证结果分别记录在HC-016，预览证据不替代原生验证。
