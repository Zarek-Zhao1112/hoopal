# 训练场观看布局 · 视觉讨论

2026-11-02；任务：[HC-047](../tasks/HC-047-training-design-concept.md)。用户确定以观看完整套战术动画为主，先交付效果图。

## 目标与非目标

突出室内木地板球场，保留顶部留白与冰川蓝/银灰玻璃框架。当前战术名作为卡内主标题；步骤只保留简短当前动作，播放控制集中。手机竖屏一屏，横屏球场扩大并将说明和播放区放右侧。底栏保持更衣室、训练场、战术库、我的。

本轮不改变正式界面、26套战术、播放节奏、自动播放策略、步骤跳转或存储；不加入新的训练课程功能。

## 候选组成与接口

战术标题与人数/攻防标签、木地板球场、辅助显隐入口、当前步骤与讲解入口、带步骤标记的进度条、上一步/暂停/下一步、倍速/循环、四项玻璃导航。暂停图标表示效果图截取的是播放中状态。各控件仍为视觉提案，合并时间轴与步骤、标题选择面板以及横屏导航位置均须在后续交互原型中验证，尚未改变现有接口。

## 数据影响与验收边界

无新增数据、接口、迁移或服务。效果图使用内置工具生成，参考既有训练场配色与材质。静态图不证明真实动画、战术防守位置、可达性、短屏或旋转行为；不得当作正式手机截图。待用户讨论确认后，再建立实现与设备验收要求。
