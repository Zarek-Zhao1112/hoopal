## 目标与边界

以 `artifacts/design/manager-style-v2.png` 为视觉依据，将现有应用统一为石墨黑 #131619、雾白 #F5F6F7、篮球橙 #F47A3C；灰色用于文字与分区，蓝色用于防守与已有档案身份。阵容卡使用独立球员卡、无袖球衣、清晰姓名和能力标签，去掉米色木纹球场背景。球员配置保留逐人、分区输入以适应小屏；演练使用深色球场和清晰控制区。

继续支持 3v3 / 4v4、手机竖屏不纵向滚动、手机横屏放大球场、平板多栏。效果图作为方向，实际布局以全部操作可达、长文本分页与小屏边界为准。无新增评分、货币、抽卡或能力推断；无战术编辑页。

- `frontend/styles/app.css`：主 agent 统一配色、导航、库、演练和弹窗外观，维护断点。
- `frontend/index.html`：主 agent 必要的语义、图标与浏览器主题色调整。
- `capacitor.config.json`、原生启动背景与现有 launcher 向量：主 agent 同步已有图标及启动表面的黑橙色值，不修改原生接口或系统行为。

- `frontend/src/app.js`：engine agent 仅调整 SVG 球场、路线、球员和导出/缩略图绘制配色，不改模板、坐标、动画、存储或身份映射逻辑。
- `shared/`、`data/`、持久化键和原生接口不改变，不迁移或清理新阵容数据。
