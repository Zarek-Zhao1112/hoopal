# 「我的」与个人账号备份

日期：2026-10-28。用户批准视觉方案，并选择第一版个人账号用于备份球队、换手机恢复。任务[HC-045](../tasks/HC-045-account-center-preview.md)已交付独立可点原型、五尺寸77HTTP/9本地file与独立审查通过；真实登录方式、服务部署和同步协议继续设计。

## 目标与页面

底栏候选为「更衣室 / 训练场 / 战术库 / 我的」。个人账号代表使用App的人；球队档案继续代表一份3v3或4v4阵容，一个账号可拥有多个档案，球员昵称不要求成为注册用户。现有更衣室、内置战术与本地推荐保持。

「我的」顶部留白、标题与紧凑个人卡；中部「我的球队」放现有队徽、名称/人数/当前使用标记、管理及创建；下部为同步与备份、设置、关于。账号与球队分区但在同页，一屏布局；窄/短屏使用紧凑分区，横屏/平板用多栏。球队增多后使用页内翻页，避免页面滚动。

未登录保留本地球队和核心演练入口，个人卡提供登录/注册。已登录示例展示昵称、账号管理及备份区。点击账号入口，半透明玻璃面板自下浮起450ms，背景同步渐暗/模糊；遮罩、关闭、本地继续、Escape退出，焦点返回触发项，期间背景控件不可交互。减少动态效果时立即到位。账户/密码字段只表达视觉层级，尚不决定实际认证方式。

## 本轮非目标与数据

原型仅演示数据，所有状态驻内存；不读取或保存本机球队，不收集输入，不访问网络，不配置账号/数据库/服务，也不写APK。切换「已登录示例」属于页面外展示控制，应用内不能把任意表单提交包装成登录成功。备份状态均注明示意，失败/未接入说明可返回，无虚构同步成功。

正式接入前仍需确定身份认证方式和服务环境。推荐行为为：未登录离线可用；首次登录明确选择是否备份本机球队；断网本地继续，联网后可重试；退出/更换账号隔离其资料，不默默覆盖现有球队；换机恢复先校验档案完整性与版本。冲突、删除、账号注销和恢复确认属于后续同步设计，不能仅沿用本地revision冒充云端并发解决。

现有存储键/原文备份/读失败锁/串行快照与推荐来源解除规则不改。账号模块、远端同步与本地档案需分层接入，不让登录状态直接改写球队仓库；当前backend仍只提供静态预览。

## 原型源码与证据

源码位于frontend/previews/account-center，普通HTML/CSS/JS，无正式入口引用；不进入默认Vite/APK打包。截图与验证保存在artifacts/design/account-center-concept，提示词和已批准PNG仍保留。验收为五尺寸三状态、开合/背景隔离/焦点/减少动效、示例球队及用途说明明确、无持久化或服务调用、正式文件hash不变；与真实登录、云备份和设备验收分开记录。

## 正式接入阶段

用户指出手机未更新后，由[HC-046](../tasks/HC-046-account-center-release.md)将布局接入正式1.24.0并更新手机。「我的球队」使用真实本地档案，原三卡分页、管理/创建、保存失败与来源协议保持；内部archives路由不改，底栏显示「我的」。账号/备份尚无可用服务，入口用玻璃面板清楚说明尚未开放，不显示示例用户、已同步状态或可提交的密码表单；不把原型示例状态搬进正式版。工具说明使用面向用户的文案，原型仍单独保留。真实身份与云备份另行接入。
