用户于 2026-10-23 批准 NBA 队徽选择与更衣室球衣联动效果图，见 `artifacts/design/nba-team-kit-concept-v1.png`。

状态：已实现，122 检查、六屏 Chrome 与独立审查通过；1.8.0 / code10 已安装指定新机并冷启，完整原生交互待验。实施证据见 [HC-011](../tasks/HC-011-nba-team-kits.md)，审查见 [独立记录](../reviews/HC-011-nba-team-kits.md)。

## 范围

- 移除创建 / 配置中的几何队徽与球队颜色选项，改为 30 支 NBA 球队的分页选择器。手机不需要纵向滚动；保留冰川蓝、银灰与玻璃导航。
- 每份阵容独立保存球队。队徽出现在档案、柜位；同阵容所有成员使用同一代表性球衣配色、字样，但保留用户姓名与号码。
- 一队一套代表性配色，不增加主客场或赛季选择。球衣为原生 SVG 布料效果；真实队徽使用 NBA 官方 CDN 资源并打包离线。
- 球队变化不影响成员能力、推荐结果和球场进攻 / 防守职责色、职责号。

## 接口与数据保护

- `data/nba-teams.js` 导出冻结的 `NBA_TEAMS` 与 `getNbaTeam(id)`；球队包含 `id`（BOS 等三字母代码）、`nbaId`、中文 `name`、`fullName`、`jersey`（`base/trim/secondary/text/wordmark`）。
- `shared/lineups.js` 增加可选 `nbaTeamId`。旧记录缺失时规范化为 `null`；保留旧 `crest/color` 字段用于兼容，不再显示旧选项。不改存储键或 schemaVersion，不在读取时自动写盘，不自动把任何球队分配给旧档案。
- 新界面创建需明确选队；旧档案可保持未选择并正常配置 / 推荐。无选择使用中性球衣和占位徽章。非法 ID 拒绝为无效输入，现有损坏记录隔离 / 备份保护继续有效。
- `frontend/src/lineups/team-assets.js` 导出 `getTeamLogoUrl(id)`，从本地 `frontend/assets/nba/*.svg` 导入；任何界面不从 CDN 实时加载。
- 选择器使用临时选中值，确认后写入创建 / 编辑草稿；取消不改草稿。档案直接换队也进入配置草稿，必须保存才落盘。离开未保存配置沿用现有放弃确认。
- 现有配置中切换队员、分区不得清空名称 / 人数 / 球队草稿。保持更衣室当前成员记忆、手势与无障碍约定。

## 验收

- 30 队唯一、标识正确，全部真实队徽可离线打开；选队、确认、取消、编辑保存与重启一致，旧档案没有数据丢失或隐式选择。
- 三人 / 四人阵容所有球衣同步，用户号码和队名不变，推荐和动画职责不变。
- 六种手机 / 平板 / 桌面尺寸没有页面纵向滚动或被导航遮挡的操作；WebView 96 兼容，不依赖 `:has` / `inert`。
- 单元 / HTTP、Chrome 真实触摸与离线流程、独立审查、APK 构建签名及资源检查分别记录。只向用户指定新手机 `ef473680` 更新；安装 / 冷启不代表原生全交互验收。
