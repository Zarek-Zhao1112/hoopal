# 演练与战术库相对阵容页的排版适配

2026-10-23。状态：用户确认最终预览后，[HC-023](../tasks/HC-023-page-adaptation-release.md)已接入1.14.0并安装指定新机；153检查/完整Chrome/最终六屏布局/独立审查通过，实际WebView程序检查通过，完整物理操作待验。此前[HC-022](../tasks/HC-022-page-adaptation-preview.md)独立预览与跟进作为历史保留。参照：[现有阵容品牌主卡](lineup-glass-sheet.md)。

## 目标与非目标

用户最终选择：仅「更衣室」（原阵容页）保留顶部库里图标/HALFCOURT/中文名称。「训练场」（原演练页）与「战术库」顶部不显示品牌，保留批准预览的卡片位置与上方留白；三页继续共享卡片起线、蓝银材质与玻璃导航。底部名称统一为「更衣室 / 训练场 / 战术库」。HC-022仅独立预览；HC-023接入正式UI与1.14.0 APK，不改变真实引擎/存储协议/数据，不增加账号或服务。

## 推荐结构

- 手机竖屏：顶部留白 → 主内容卡 → 导航；训练场/库去掉品牌但不回填其空间，卡片不向上移动。更衣室品牌保留。360×640继续沿用短屏留白，确保动作完整。
- 演练：卡内页面标题/人数/更多 → 战术选择与对手显隐 → 室内木地板球场 → 步骤/讲解 → 播放/速度/进度。避免页头重复展示战术名；常用控件始终可见，完整讲解由弹层呈现。
- 战术库：同卡内标题/数量/人数 → 攻防切换 → 纵向标题叠卡。默认全部收起、点单卡开再点收、换卡收旧，展开可见球场缩略图与开始演练。人数/攻防只筛选，明确开始演练才跳到演练示意。
- 手机横屏：沿用紧凑顶部留白，左侧大球场、右侧回放/讲解；库标题与筛选横向排布，卡片可两列。平板横屏扩宽内容，维持原卡片位置，球场优先。

## 接口与数据影响

独立预览位于artifacts/design/page-adaptation-preview，原生经典脚本支持file直开，本地资源来自仓库。window.adaptationPreview提供setView/getState用于验证，数据仅当前网页内存；不读写localStorage、原生文件或阵容。示例播放清楚标示演示，不伪装正式战术引擎；导出等未实现入口须明确说明。

正式版保留原控件ID与真实20套动画，训练场主卡容纳球场/回放/人员图例/4或6步及分页，库继续真实标题deck测量与来源协议。唯一#mode随页面在#play-header-controls与#library-header-controls移动，值分别反映真实演练人数/库浏览人数，事件、busy和modal锁仍由app管理；#open-menu位于训练场卡内，#play-title只读元数据保留。布局通过定向page-layout.css适配，禁止把预览示意引擎或内存样例接入正式流程。没有存储迁移。

## 状态与验收

普通演练/播放/暂停/步骤/讲解，库默认收起/单卡展开/换卡/筛选/开始演练，旋转与低高度均保留可达控件。四尺寸两视图实际Chrome检查无整页溢出、控件命中/图片加载，展开CTA不被导航遮挡，无远程或存储请求；交付对照PNG及本地入口，独立审查记录发现与修复。无需为本地预览伪造加载/错误，不替代正式兼容或设备验收。
