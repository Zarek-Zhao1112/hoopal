# 全页面统一排版 · 讨论稿 v1

日期：2026-10-23。任务：[HC-018](../tasks/HC-018-unified-screen-spec.md)。本稿依据1.12.0现有功能盘点，**只提出排版与状态规范，不代表新增交互已经实现，也不授权直接改APK**。用户已定约束继续有效；以下尺寸、骨架与确认浮层等为待讨论建议。

## 1. 统一框架

### 已定约束

- 三个主入口固定为「阵容 / 演练 / 战术库」，玻璃导航与600ms柔光切换保留，位置不随正文长度跳动。没有编辑页、个人战术库、战术导入或账号。
- 冰川蓝/银灰承载页面，更衣室承载队员，室内木地板承载球场。库里头像用于App识别，不自动变成全屏常驻装饰。
- 手机竖屏主界面不整页上下滚动；长内容用分区/分页/点开全文。横屏扩大球场；平板横屏允许多栏。
- 球衣区域左拖到下一位，右拖回上一位；只在场景内识别，不把全页左右滑当换页。
- 战术库默认全部标题收起，点一张展开、同卡再点收回、换卡收旧卡，无统一展开按钮。浏览人数/攻防与标题不改变演练或本队来源。
- 阵容表单明确保存才落盘；只选球队仅写本次草稿；读取失败不拿默认值覆盖，写失败保留输入与重试。

### 建议统一的页面骨架

效果预览后用户要求顶部增加留白，避免标题和内容贴满屏幕上沿。HC-019预览采用普通竖屏44px、低高度竖屏28px、横屏16px的顶部内边距，固定底部导航。尺寸为视觉讨论值，正式接入还需与系统安全区合并计算，不能在状态栏留白之上机械重复叠加。

最新阵容迭代进一步确定「顶部项目图标＋项目名称，下面才是内容卡」；阵容主卡缩小、单柜居中，卡内保留「我的阵容」。用户希望其他页面后续也沿用品牌区，这取代了早期取消顶部品牌行的建议；本轮只更新阵容预览，其他页面尚未制作该版效果。

现状与提案分界（不能将讨论规范写成当前验收结果）：

| 项目 | 1.12.0现状 | 本稿建议 |
| --- | --- | --- |
| 首次加载 | 顶层等待本地读取后初始化，静态页面壳；无专用骨架 | 延迟出现、按目的页几何绘制的骨架 |
| 读取失败 | 存储层锁写，UI提示与重试；未统一禁用所有编辑入口 | 显式错误/受限状态，避免用户误以为可保存 |
| 主导航与草稿 | 主导航换页保留内存草稿；子页返回触发三选确认 | 保留这一区分；不在每次切导航新增确认 |
| 推荐入口播放 | 载入人员映射并切到演练，当前不自动播放 | 是否与库入口统一自动播放，单独讨论，暂不默认改变 |
| 库入口播放 | CTA成功载入后自动播放 | 保留；预览与筛选仍不加载 |
| 确认与全文 | 删除/草稿是页内确认，全文共用note-dialog | 确认可统一视觉容器；浮层化/全文长按复制是建议 |
| 长按 | 无自定义业务动作；输入使用系统能力 | 不新增隐藏业务动作；正文复制需验证后实现 |

实际主路由只有lineups/play/library；下文S编号是设计屏幕/子态编号，不是新增URL或16个底部入口。

```text
系统安全区
顶部留白
项目品牌：图标 / 项目名称
┌ 页面栏：返回(子页) / 标题 / 一个主要辅助入口 ┐
│ 上下文：阵容名、人数、当前来源等至多一行     │
│ 局部切换：人数/攻防、队员、配置分区等       │
│                                            │
│ 主内容区：场景、球场、表单或标题卡          │
│                                            │
│ 状态/错误提示：有内容才出现                 │
│ 本页操作区：一个主要动作 + 必要次要动作     │
└ 底部玻璃导航：阵容 / 演练 / 战术库 ────────┘
系统手势安全区
```

不是每页占满所有行：没有切换或操作就将空间还给主内容。演练的回放区替代通用操作区，战术库的开始按钮位于展开卡内部，不能另复制一个页面级开始按钮。

拟议排版量尺：页面左右16px、紧凑屏12px；区块间12–16px、组件内8px；标题22–24px、正文13–14px、辅助11–12px，禁止用极小字硬塞主要说明；常用按钮高度44–48px，拟以44px作为正常支持尺寸下的验收下限。页内卡片圆角12–16px，同层卡使用相同边框/阴影。这里只是本项目建议，不声称现有代码已全部达到。

同一区域只有一个强主按钮：创建/保存/推荐演练用实色蓝，其余次操作用浅底描边；删除用低饱和危险色。切换项使用短段选控件，页码统一「上一页 — 1 / N — 下一页」，首尾明确禁用。

### 全局交互与状态

- 点击：可见动作均有明确按钮，不靠长按发现入口。截断队名/昵称/职责/说明可点开全文；不靠悬停提示。
- 滑动：仅球衣场景负责切队员、时间轴负责拖进度、系统负责边缘返回；卡片开合/球队分页/档案分页/推荐候选先用点击。其他区域横滑或竖滑不改变业务状态。
- 长按：普通卡片、球衣、队徽、导航不新增业务动作，不触发删除/保存/拖拽排序；输入框及可复制全文保留系统文本操作。以后若增加快捷入口，必须同时有可见按钮，另行讨论。
- 主导航离开演练先暂停，回来保留当前阶段，不隐式重播；重新进入战术库回到全收起。配置中切主导航保留本次内存草稿，不隐式保存；返回/放弃才进入现有未保存处理流程。
- 操作加载只锁相关按钮与冲突操作；正在保存或切换来源时禁止重复提交，不用全屏骨架替换已填写表单。由完成/失败事件解锁，不由固定倒计时假定成功。
- 空状态只用于已经读取成功且确实没有内容；「仍在读取」「读取失败」「队员未配置」不能冒充0档案。
- 本地离线应用不加假网络延时。建议真实读取超过约150–200ms才显示骨架，数据提前完成就直接呈现；骨架与目标几何相同、不可点击、读屏只播报一次正在读取。减少动态效果时用静态灰块，不强制闪烁。
- 错误在相关区域说明原因与下一步：输入问题贴字段，保存失败贴操作区，读取失败用状态卡和重试。短toast仅作补充，不能成为保存失败唯一证据。不恢复已移除的常驻离线口号。

## 2. 逐屏规范

下列每屏包含五项；**组件为目标画面清单，交互沿用现有能力或在建议处明确说明**。基础标题/状态/玻璃导航等共用组件不代表重复渲染两套。

### S00 · 启动与本地读取

1. **线框**：系统启动图标 → 球搭HOOPAL品牌与圆角取景窗 → 真实更衣室内容/空/错误之一。2026-10-27用户批准HC-037展开效果并授权[HC-038](../tasks/HC-038-hoopal-startup-release.md)正式接入，替代早期直接进入的方案；可跳过、不在切页或后台恢复时重复播放。
2. **组件**：已有App图标、页面框架占位、读取状态、读取失败提示与重试；初始化完成后才显示可用导航与编辑操作。
3. **交互**：点击重试重新读取失败的数据域；读取时不能创建/保存覆盖未知旧资料。滑动/长按不设业务操作，系统返回遵守原生生命周期。
4. **空/错误**：读取成功且0档案进入S01空柜；阵容读失败显示「阵容暂时无法读取」而非空柜。内置资料仍可用时允许独立浏览演练，锁住受影响的写操作；未知数据版本明确告知无法安全写入。
5. **加载/骨架**：短读取不闪屏；较慢时显示标题条、柜位大矩形和详情条骨架，无假队员名/假档案数。重试只替换读取失败区域。

### S01 · 阵容首页 / 更衣室

1. **线框**：标题+创建 → 阵容身份条 → 单人更衣柜 → 球员位置控件 → 当前队员详情 → 推荐/配置 → 档案分页 → 玻璃导航。
2. **组件**：我的阵容标题、档案数量/20、创建；NBA队徽、阵容名、3v3/4v4、配置状态、是否当前阵容、球队名、更换球队、删除；柜位铭牌/球衣/号码、左右箭头/圆点/第几位提示；姓名/号码、身高/体格/移动、擅长/弱项；查看进攻推荐、配置或继续未保存配置、非当前档案的设为当前、档案前后页/页码。建议把更换球队/删除等低频操作收为显式「更多」菜单，待单独确认，现有按钮不能被长按取代。
3. **交互**：柜位内左拖下一位、右拖上一位，有首尾限位和按钮替代；切队员不写盘。点姓名/标签看全文；配置打开当前队员；档案翻页只浏览，点设为当前或进入非当前档案推荐走现有成功切换路径。删除先S12，创建进S02。长按无隐藏业务动作。
4. **空/错误**：0档案保留空柜、简短解释、创建我的阵容，并可从底导航看战术；缺能力显示待完善，不伪造评分。读取失败改用错误卡+重试，不能显示正常空柜；设当前/删除失败保留原档案和选择，不表面成功。
5. **加载/骨架**：首次真实读取慢时柜位+详情骨架；已有数据下切换档案/保存时保留当前画面，只显示局部处理中并锁冲突控件。图片异常用中性队徽/球衣占位，不能删成员。

### S02 · 创建阵容

1. **线框**：返回+创建阵容 → 阵容名 → 人数段选 → 球队摘要入口 → 创建并配置球员 → 玻璃导航。
2. **组件**：阵容名输入/40字限制、3v3/4v4、NBA队徽/球队名/更换入口、人数创建后固定说明、字段错误、创建按钮、返回。避免重复的大幅IP插画挤占表单。
3. **交互**：点人数只改草稿；点球队进S03，确认仍是草稿；点击创建通过校验与持久化成功后才转配置。返回未完成创建触发S13，切主导航保留本次草稿；输入长按为系统编辑，空白区域滑动不提交。
4. **空/错误**：初始空白是正常表单；阵容名空/未选NBA球队明确定位字段；达到20份显示容量说明并提供返回管理，不把创建失败说成创建成功。写失败保留名称/人数/球队可重试。
5. **加载/骨架**：打开本地空表单无需骨架；提交按钮显示创建中、禁止重复点，字段保持可见。键盘出现缩减装饰并保住输入与底部主按钮，不让页面整页滚动。

### S03 · 选择 NBA 球队

1. **线框**：返回+选择球队 → 分页球队网格 → 页码 → 当前暂选摘要与球衣 → 取消/确认 → 玻璃导航。
2. **组件**：30队本地队徽与短名称、每页最多12队/共3页、选中标记、上一页/页码/下一页、暂选完整队名/队徽/当前球员球衣、只加入草稿提示、取消、确认选择。平板可改变网格列数但不丢项目。
3. **交互**：点队伍只暂选，换页保留暂选；确认回原创建/配置页并更新草稿，仍需原页创建或保存才落盘；取消/返回丢弃此次暂选，原草稿不动。无全网格滑动分页，长按不替代确认。
4. **空/错误**：没暂选显示请选择且禁确认；旧档案可以取消保持中性。队徽图片缺失用球队缩写占位、文字与选择仍可用；本地资源异常不显示网络登录/联网按钮。
5. **加载/骨架**：本地列表通常直接显示；仅缺图片的单格用静态占位，不整页闪骨架。不为纯内存确认添加保存中或假进度条。

### S04 · 配置球员—资料

1. **线框**：返回+配置球员+队伍 → 队员切换 → 当前球衣与身份字段 → 资料/体型/擅长/弱项 → 草稿状态+保存 → 玻璃导航。
2. **组件**：阵容名/人数、3或4队员按钮、当前队员标识/球衣、昵称输入/24 UTF-16限制、球衣号0–99输入、号码不重复说明、分区切换、队伍入口、保存配置、返回、草稿/字段错误。球衣号与动画职责号分开解释。
3. **交互**：点队员或分区保留已填草稿；姓名可留空，号码必填。保存验证整个阵容并写入成功后才离开；返回有修改进S13；导航切页保留草稿。长按仅输入框系统编辑，不在表单内引入横滑切队员。
4. **空/错误**：空昵称显示默认队员名，不是错误；空/越界/重复号码定位对应队员，保留其他字段。保存失败不销毁输入，也不宣称自动保存。
5. **加载/骨架**：本地切分区不显示骨架；保存按钮处理中并锁冲突操作，不盖住表单。建议键盘抬起时缩小/隐藏球衣装饰，主操作靠键盘上沿；全局导航临时压缩或隐藏属于待确认建议。

### S05 · 配置球员—体型

1. **线框**：共用配置框架 → 当前球衣/队员 → 身高三选 → 体格三选 → 移动三选 → 分区/保存。
2. **组件**：S04共用栏、身高偏矮/中等/偏高、体格偏瘦/中等/强壮、移动偏慢/一般/灵活、每组单选态/待选态、能力不由体型推断的简短说明。
3. **交互**：点标签单选，可切队员补齐；选择只改草稿，保存才落盘；滑动/长按不改变标签或评分。没有身高体重数值输入，也不自动生成数值战力。
4. **空/错误**：未选显示待选并可先保存不完整档案；只有请求推荐时引导补齐。读/写失败按S04保留表单，不把待选当弱项。
5. **加载/骨架**：标签切换即时，无骨架；保存状态共用S04。

### S06 · 配置球员—擅长

1. **线框**：共用配置框架 → 队员 → 擅长计数 → 六个能力标签 → 规则提示 → 分区/保存。
2. **组件**：投射/突破/传球/控球/掩护/篮下终结、0–3计数、选中态、和弱项冲突提示、未标按一般说明、共用保存区。
3. **交互**：点选/再点取消，最多3项；满额后解释需先取消，不静默替换最早标签。与弱项冲突时提示先取消另一处；无拖动排序和长按升级能力。
4. **空/错误**：0项是合法的一般能力；超额或冲突是就地校验，既有选择不丢。写失败保留草稿。
5. **加载/骨架**：点选无加载，保存仅按钮处理中；不生成雷达图骨架或假评分。

### S07 · 配置球员—弱项

1. **线框**：共用配置框架 → 队员 → 可选弱项计数 → 六个能力标签 → 可留空说明 → 分区/保存。
2. **组件**：同六项能力、0–2计数、弱项选中态、与擅长冲突提示、共用保存区；弱项不使用破坏性删除按钮样式。
3. **交互**：点选/取消、最多2项；冲突不自动修改擅长。其余切页/保存/返回沿S04，长按无业务操作。
4. **空/错误**：不选合法，不弹缺失警告；只提示超额/冲突/写失败，保存失败保草稿。
5. **加载/骨架**：点选即时，保存状态同S04，无整页骨架。

### S08 · 配置队伍

1. **线框**：共用配置页标题 → 阵容名称 → 当前NBA队伍摘要/更换 → 对队员无影响说明 → 保存配置。
2. **组件**：阵容名输入、队徽/完整队名、选择球队按钮、队员/配置分区返回入口、昵称号码能力保留说明、错误、保存/返回。
3. **交互**：点更换进S03，确认仅改本次草稿；保存成功才应用全队队徽/球衣，不改队员标签。现有入口是配置页右上「队伍」，不新增一个底部主导航页。长按输入走系统操作，其余不设动作。
4. **空/错误**：旧档案未选球队可保持中性，不自动分配；不合法队名或写失败保留草稿，其他档案不受影响。
5. **加载/骨架**：打开即显示草稿，局部图片占位；保存中锁相关操作，无整页替换。

### S09 · 进攻推荐

1. **线框**：返回+进攻推荐+配置 → 候选切换 → 战术名/适配提示 → 木地板缩略图 → 特点/理由/分工/提醒 → 分页正文 → 按本队分工演练 → 玻璃导航。
2. **组件**：阵容名/人数、最多3个候选标题、适合尝试/有条件备选、战术初始站位图、四分区、正文/职责到昵称与球衣号映射、前后页/页码、未保存配置提示、配置入口、演练主按钮、返回。
3. **交互**：点候选/正文分区只查看；分工逐页覆盖所有队员。开始本队演练走既有来源持久化成功路径，不能仅换界面；当前进入演练后需要点播放，不写成已经自动播放，统一自动播放须另行确认。图为预览不能拖编辑；滑动不偷偷换候选，长按不更改推荐排名。
4. **空/错误**：缺体型说明哪些队员待完善并进配置；已配置但无候选单独解释，不假造第一名。不完整能力标签仍按一般，不强制填写擅长。未保存草稿时明确按已存档案推荐；来源/选择写失败留候选供重试。分阶段处理：清旧来源本身写失败保留旧对应；若已成功解除而后续选择/新来源写失败，保持安全的无来源状态，不回挂旧人员，也不假播放新候选。
5. **加载/骨架**：本地计算通常即时，不故意等待；真正较慢仅图/正文区域骨架，标题和返回保持。演练提交时按钮处理中，保留当前推荐，完成才导航。

### S10 · 战术库

1. **线框**：统一标题栏+人数 → 进攻/防守 → 本组数量 → 全部标题卡 → 展开卡内球场/说明/开始演练 → 玻璃导航。
2. **组件**：战术库标题、3v3/4v4、进攻/防守段选、6套进攻或4套防守数量、序号/战术名/展开箭头、单卡内类别/人数/初始站位SVG/摘要/开始演练；必要时局部错误与重试提示。没有战术分页、全开开关、创建或导入。
3. **交互**：默认全收起；点标题开/同卡关/换卡收旧，筛选和重入重置；浏览不写真实演练或推荐来源。开始演练清来源成功才载入并自动播放，重复提交只执行一次。卡片/球场不拖拽编辑，滑动/长按无额外业务动作。
4. **空/错误**：固定内置目录正常不为空，真的缺资源显示不可用/重试而非创建战术。缩略图失败用站位图暂不可用占位，标题仍读得清；来源清除失败保留开卡/旧来源、不跳演练。
5. **加载/骨架**：默认标题直接显示，不为每次开卡闪骨架；首次构图慢只占位图区域。CTA载入中禁重复，保留卡；不显示伪下载进度。

### S11 · 战术演练

1. **线框**：战术标题/来源/人数/更多 → 攻防与战术选择 → 完整半场 → 本队职责摘要(如有) → 当前步骤短讲解/全文入口 → 播放/速度 → 进度/循环 → 步骤选择 → 玻璃导航。
2. **组件**：内置战术名、3v3/4v4、进攻/防守标识、同组选择器、显示对手开关、球场与棋子/职责号/篮球/路线；本队来源名、完整图例入口/前后页(仅推荐来源)；短讲解、讲解按钮；上一步/播放暂停/下一步、步数、0.5/1/1.5/2倍、重播、时间轴/百分比、循环；步骤编号/步骤分页、更多导出入口。
3. **交互**：播放后棋子移动，暂停保留当前阶段；拖时间轴只改进度，松手停最近完整步；点击步骤跳步。球场点击/拖动不编辑站位，长按不召出编辑菜单。点全文进S14，更多进S15；离页暂停，手机旋转不换战术/来源或丢进度。播放时不允许冲突的模板切换，需先暂停。
4. **空/错误**：无本队来源直接隐藏身份图例，不显示「暂无阵容」占球场；空讲解用此步暂无说明。恢复ID失效按现有合法内置回退并提示；真实资源不可用不能继续假播放。来源/进度写失败不宣称已记住，保留画面和可重试入口。
5. **加载/骨架**：首载慢可用球场比例灰块+控制条占位；真实载入后再出现球员。切战术保留上一个有效画面并显示载入中，失败仍可回原画面。播放过程不显示骨架/加载转圈，不给动画叠无关IP动作。

### S12 · 删除阵容确认

1. **线框**：当前确认层标题 → 明确阵容名/人数与影响 → 保留/删除两个按钮。建议统一为居中确认卡或底部确认层；现状是阵容页内确认面板，浮层化尚未实施。
2. **组件**：删除这份阵容？、对象名称、删除成员及该档案关联信息的说明、保留阵容、删除阵容与成员、处理中/失败。不能暗示删除内置战术或其他档案。
3. **交互**：明确点删除才提交，返回或取消保留；不采用长按即删除。处理中锁重复删除与冲突切换；失败留原对象供重试。建议遮罩点击仅取消且不触底层按钮，具体视觉待确认。
4. **空/错误**：对象已不存在时禁删除并回到有效列表；写失败仍显示原档案，不能先移除再悄悄失败。
5. **加载/骨架**：确认文字直接显示，不用骨架；删除按钮变处理中，成功才关闭并刷新。

### S13 · 未保存配置确认

1. **线框**：配置尚未保存 → 草稿只保留本次会话说明 → 继续配置 / 保留草稿返回 / 放弃本次修改。建议与S12同容器；现状为页内确认面板。
2. **组件**：标题、影响说明、三项明确动作、需要时具体档案名；保留草稿不等于已保存，不能显示保存成功勾。
3. **交互**：继续回原字段；保留草稿返回首页，后续可继续本次配置；放弃只清当前编辑或创建草稿。返回关闭确认并回到表单，不改变其他档案草稿；滑动/长按不保存或放弃。
4. **空/错误**：编辑页没有改动不出现；现有创建页只要已有createDraft，哪怕仍是空白创建，返回也会确认，本稿先保留该规则。若希望空白创建免确认，应另列交互提案。不把内存草稿描述为杀进程后可恢复。保留/放弃内存草稿本身不应出现磁盘写失败状态，保存需回配置显式执行。
5. **加载/骨架**：即时确认，无骨架、无伪保存中；若未来合入直接保存按钮，需另定真实写入规则，当前不新增。

### S14 · 完整讲解 / 队员资料 / 标签 / 职责文本

1. **线框**：标题+关闭 → 定高分页全文 → 上一页/页码/下一页。小屏采用大弹层；同一全文容器承载不同内容。
2. **组件**：具体内容标题、原文段落、完整队名/昵称/号码/标签或职责、页码、前后页、关闭。没有编辑框、保存或分享新入口。
3. **交互**：点前后页读完，关闭回原触发点；Android返回/Escape关闭；旋转尽量保留字符位置。建议正文支持系统长按复制，属于拟议新增，现有CSS/读屏表现需实施时验证；滑动不换整页或更改数据。
4. **空/错误**：空讲解说明此步暂无讲解；失效对象提示资料已变化并关闭/返回，不拿别人的内容替代。长名/换行/emoji不能靠截断丢原文。
5. **加载/骨架**：本地文字直接呈现，无骨架；测量分页不造成空白闪烁，超过容量分更多页。

### S15 · 导出菜单与系统分享交接

1. **线框**：战术文件标题+关闭 → 导出当前步骤图片 / 导出战术文件 → 格式说明；选择后进入系统分享界面（外部平台界面，不重新设计一套）。
2. **组件**：PNG入口及当前步说明、JSON入口及完整内置战术说明、关闭、生成中/失败/取消反馈；文件名沿当前战术命名。导出对象必须明确为当前已载入战术，不是库中仅展开的预览；人员身份仅界面图例，不擅自塞进兼容JSON。
3. **交互**：点格式生成相应文件；生成中防重复提交；系统取消回App不记为文件已保存，交接成功只能说已打开分享。长按不触发导入或清理，滑动不执行导出。返回先关菜单或系统面板，不丢当前战术步骤。
4. **空/错误**：正常总有当前内置战术；确实无有效战术时禁导出并说明。文件生成/缓存/分享失败分清并给重试，保留演练画面；用户取消用中性反馈，不报失败警告。
5. **加载/骨架**：生成图片显示生成中并锁该操作，不替换整个球场为骨架；不伪造百分比，不把分享面板打开算对方收到了文件。

## 3. 横屏和平板规则

| 屏幕类型 | 阵容/创建/配置/选队 | 战术库/推荐 | 演练 |
| --- | --- | --- | --- |
| 手机竖屏 | 单列；柜位/球衣在上，标签或字段在下；当前分区一屏；球队网格分页 | 标题卡纵向；推荐图/正文分区；主操作在导航上方 | 完整半场在上，讲解与回放在下；收缩装饰不裁球场 |
| 手机横屏 | 场景/球衣左，详情/表单右；减少副标题；主动作在右区底部 | 全收标题可两列；开卡左详情右其余标题；推荐左图右正文 | 左侧最大完整球场，右侧步骤/回放/图例；底导航位置与右区操作互不遮挡 |
| 平板横屏 | 左档案/队员摘要，中柜位或球衣，右详情/配置；不同时显示重复编辑表单 | 库左标题选择右选中卡；全收时无预选大图；推荐图与正文分栏 | 中大球场+右步骤/讲解与回放；步骤和本队图例完整可达 |

以上分栏是建议方向，触发阈值按实际内容区域测量，不拿键盘压缩后的高度误判手机横屏。旋转保持档案/球员/当前分区/已填草稿/推荐候选和演练阶段，卡片展开在同组可保留；新入库或变筛选仍全收起。现有横屏各页导航位置存在差异，本轮建议统一一个稳定且预留空间的导航停靠区，具体停靠设计待线框比较后定。

## 4. 共用状态文案与验收

| 状态 | 示例 | 行为 |
| --- | --- | --- |
| 真正为空 | 先组一支自己的球队 | 已读取成功；提供创建与战术库可见入口 |
| 待配置 | 还有队员的体型未选择 | 可继续保存不完整档案；推荐时引导补齐 |
| 读取失败 | 阵容暂时无法读取，点此重试 | 不伪装空列表，不允许默认覆盖未知数据 |
| 保存失败 | 配置未保存，已填内容仍保留 | 留原表单/卡片，允许重试，不导航假成功 |
| 来源切换失败 | 暂时无法切换演练，请重试 | 清旧来源写失败保旧对应；已解除后再失败保持无来源，不回挂旧人员，不假播放新候选 |
| 损坏数据或备份失败 | 部分资料无法读取，原资料尚未安全备份 | 不覆盖损坏原文；隔离合法与异常数据，不能承诺未实现的一键恢复 |
| 旧个人数据清理失败 | 旧个人战术资料未能清除，可重试 | 保留既有授权清理流程，不自动归档/恢复个人战术 |
| 分享取消 | 已取消分享 | 中性反馈，不等于错误或对方已保存 |

实施前需对照现有存储/来源合同，不用视觉统一改写其语义。最低验收拟覆盖360×640、390×844、844×390、1024×768、1280×800、1440×900；每屏检查内容完整性、真实可见按钮命中、无整页滚动/导航遮挡、长名/emoji/换行、键盘与减少动效、无假加载、读/写失败和操作中断。浏览器、APK编译、安装和真机手指/返回/旋转验收分别记录。
