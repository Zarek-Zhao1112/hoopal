## 最新确认：默认全部标题收起

用户明确选择「所有卡片都只显示标题，不显示球场，也去掉展开／收起按钮；点某张才展开」。主控更新现有HTML与截图脚本，首版HTML保留为 `v1-stack.html`，旧验证脚本保留 `artifacts/design/render-stacked-preview-v1.mjs` 仅作历史参考。

当前 `index.html` 默认selected=-1，所有card-body有hidden，所有标题可点；点同卡切回-1，换卡只显示新卡内容；筛选组重置-1。去掉统一按钮，卡顺序固定，不再选卡置顶。`all-collapsed.png`为新默认页，`comparison.png`及其他PNG均已重拍为最新方案。

主控真实Chrome验证默认全收起/无按钮、点第一张开/切第三张/再点收、快速连点、四组人数攻防重置与计数；五尺寸frame与普通链接无页面溢出、标题中心均可点，reduced-motion可用，无运行错误或远程请求。独立reviewer执行当前实际脚本状态夹具、隐藏焦点/aria检查与最终图检，记录追加于同一审查文件。正式源码、版本和手机1.10.0未改。
