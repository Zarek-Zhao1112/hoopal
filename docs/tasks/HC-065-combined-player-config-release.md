# HC-065 · 正式接入统一球员配置

状态 `awaiting_device`。将已确认的 [HC-064](HC-064-combined-player-config-preview.md) 合并原型接入正式更衣室、球队管理和建队球员步骤。已覆盖安装并完成设备程序检查，物理操作体验待确认。

- 一张球员卡编辑昵称、号码与可选通用角色。切换队员保留整队草稿，一次保存。取消沿用草稿保护。
- 沿用 schema 2 和可选 `mainRole`。角色集按人数限制，允许重复或清空。身份、角色同一事务。旧调用只编辑身份时继续保留角色。
- 不改战术模板、阵容人数和战术进度持久化。
- 分别验收存储兼容、浏览器入口和保存、APK 与设备安装。构建版本 1.31.0 / code 37。

建队时切换人数会分别保留两种人数的角色草稿，昵称和号码随共有球员保留。直接配置可从更衣室和球队管理打开。打开保留的草稿时，若仅有体型等非编辑元数据改变，会同步版本并继续编辑。详见 [独立审查](../reviews/HC-065-combined-player-config-release.md)。
