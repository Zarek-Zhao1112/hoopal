# HC-077 · 4v4 主副通用角色与战术位置映射

用户同意将 4v4 调整为持球发起、掩护配合、接球策应、空间拉开、得分终结五类角色，并沿用主角色优先、副角色次之、阵容顺序补位、每名球员只占一个位置的规则。沿用 HC-076 的当前约定：主角色和副角色都可暂不设置，角色可重复。详细接口和兼容边界见[设计记录](../design/team-role-mapping-4v4.md)。

保留旧 4v4 `mainRole: space` 为独立兼容角色，不自动解释为 `spacing` 或 `finisher`。旧 ID 在九套进攻里继续匹配其历史位置；新配置可分别选择空间拉开和得分终结。新增 `secondaryRole` 允许 4v4 队员配置副角色，但本任务不加入副角色编辑控件，也不改变现有前端布局。
