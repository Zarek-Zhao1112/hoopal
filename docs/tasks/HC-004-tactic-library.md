# HC-004 扩充可播放战术库

日期：2026-10-22。状态：`completed`。

## 目标与范围

用户要求增加战术。现有 3v3 三套、4v4 一套，本轮扩充到各六套、合计十二套；新增配合具备完整分步站位、动作路线、持球变化和中文讲解。手机可直接从球场上方选择示例。

保留原四套模板 ID、顺序、起始示例和用户战术格式，不改存储键或覆盖个人战术。完成自动验证、独立审查并构建新版测试 APK；手机安装状态另行按实际记录。

关联设计：[战术库扩展](../design/tactic-library.md)。关联审查：[HC-004 审查记录](../reviews/HC-004-tactic-library.md)。

## 接口与顺序

模板对象保留 `id/title/description/mode/build()`，可增加 `category`、`difficulty`；`build()` 仍返回兼容的 Play。新增 ID 稳定且唯一。顶部 `#template-picker` 按当前模式列出模板，`#template-count` 显示当前模式套数；个人战术不强行标记为内置示例。

主 agent 先写范围和接口，数据与界面并行实施；数据完成后集成选择器并检查动画和旧草稿兼容，再独立审查、修复、构建 APK。

## 实施与审查进展

新增数据按人数拆入 `data/tactics/`，分类 / 难度只用于模板列表。版本更新为 1.1.0（versionCode 2），不改 Play 格式、存储键或应用包名。

独立审查发现新增六套的部分传球动画会穿过防守球员图形，已调整协防和回扑位置，同时修复高低位首段同类问题。新增动态间距回归后，57 项单元 / 集成检查全部通过；reviewer 按更密集的 0.001 进度采样独立复验通过，无未修复的新增 P1 / P2。

扩大浏览器检查为逐套实际播放后，复现快速切换并重播时首个 requestAnimationFrame 时间戳早于启动时 performance.now()，导致负进度、访问不存在的步骤并停止动画。主 agent 将时间增量限制在 0–0.1 秒，按相同逐套播放流程回归，并交独立 reviewer 复核。此修复纳入本任务的播放可靠性范围。
