# HC-072 · 整张更衣室卡片滑动原型

目标是在现有写实和玻璃界面演示从标题、球队信息、画面、留白、圆点和底部按钮上横滑切换一位球员。竖向手势交给浏览器，轻点继续触发原按钮，滑动完成后「编辑球员」打开新选中的球员。

原型入口为 `/?locker=card-swipe`，通过双外观预览服务使用示例球队。改动限定在预览入口和预览手势层，不改变正式入口、存储格式或 APK。验收关注按钮起滑时的跟手动画、放手后的选中位置和轻点编辑。

状态 `completed`（原型交付）。Chrome 390 × 844 以模拟触摸核对写实外观从编辑按钮起滑、放手切到 11 号、轻点打开 11 号单人编辑，以及玻璃外观从球队信息起滑切换。三帧效果图位于 `artifacts/qa/hc072-card-swipe/gesture.png`。
