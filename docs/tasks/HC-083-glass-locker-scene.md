# HC-083 · 玻璃更衣室整卡场景

状态：`awaiting_device`（1.36.1 已保数据安装并在真实 WebView 核对，待用户手动体验）。

## 目标与授权

用户在 A / B 灯光对比及 C 玻璃插画方案中选择 A，并确认接入：玻璃更衣室复用写实场景构图，浅蓝雾面与暖色柜灯结合，场景铺满整张卡片。球衣清晰，两个底部按钮等宽。设计见 [玻璃更衣室场景](../design/glass-locker-scene.md)。

## 实现边界

- 主控负责 `frontend/styles/appearance-locker.css` 和任务、设计记录。
- 集成核对发现启动快照直接读取现有球衣视口；整卡模式下该视口只含球衣。补充 `frontend/src/startup/controller.js`：在脱离更衣室场景样式的临时柜体中冻结原单柜开场，完成后清理；保持原时间线、跳过与数据读取保护。
- 复用本地竖/横更衣室图片，共享球衣和圆点的场景位置；仅玻璃外观增加明亮冷蓝雾面和玻璃按钮。
- 维持整卡横滑、当前球员编辑、键盘切换；不改球队与战术存储，不增加外部资源。
- 用户追加要求手机体验：1.36.1 / code46，构建、安装、真实 WebView 程序核对与用户手动确认分别记录，不能用网页证据代替。

## 验收

- 检查常规竖屏、短屏、横屏、桌面；场景铺满、球衣可见、等宽按钮可点击且无页面溢出。
- 实际横滑与单人编辑入口一致；外观切换后场景位置相同，写实外观无视觉回归。
- 检查无球队时的空卡、长球队名和四人阵容。
- Vite 构建、相关浏览器回归和视觉核对，记录真实结果。
