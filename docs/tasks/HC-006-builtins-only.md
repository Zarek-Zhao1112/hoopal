# HC-006 统一使用内置战术

日期：2026-10-22。状态：`completed`。设计：[内置唯一来源](../design/builtins-only.md)。审查：[HC-006](../reviews/HC-006-builtins-only.md)。

## 用户范围与数据授权

用户明确要求删除「我的战术」，统一使用内置战术。本轮移除个人库、保存 / 新建 / 自定义导入入口及切换自动归档，启动时清空旧个人库和旧草稿。此删除已经获得用户直接授权，不另行确认，不以旧版“保存前备份”逻辑重新保留或恢复已删除内容。仅处理本应用个人库 / 草稿及其 WebView 原始键，不清除其他应用或系统设置，不删除用户导出的文件。

十二套内置配合为唯一来源；保留临时编辑、步骤、动画、讲解和 PNG / JSON 导出。临时调整不持久保存为个人战术，重新载入 / 重启恢复内置数据；仅记住当前内置模板 ID 和可用步骤。界面明确提示临时调整的保存范围。

## 分工与接口

| 负责人 | 独占可写范围 | 交付 |
| --- | --- | --- |
| 主 agent | 文档、版本 / 构建配置、测试与交付 | 回归、清除结果核对、新 APK 与安装 |
| ui | `frontend/index.html`、`frontend/styles/app.css` | 移除个人库、新建、保存、导入及来源切换，维持三种一屏布局 |
| engine | `frontend/src/app.js`、`frontend/src/workspace/controller.js`、新增 `frontend/src/storage/builtins.js` | 内置启动 / 选择状态、授权清理旧数据、移除自动归档与个人功能事件 |
| interaction_design | 只读 | 删除范围、失败处理、状态恢复及布局独立审查 |

删除的 DOM 接口：`#save-play`、`#new-play`、`#saved-list`、`#saved-page-*`、`#import-file`、`[data-library-source]`；`#template-list/picker/page-*` 保留。`#play-title` 可保留只读 input 方便现有控制，不支持改名。旧通用 repository 模块作为历史兼容代码保留，但应用不再读取它的个人数据或调用保存个人库。新增持久化模块仅存内置模板 ID / 步骤，数据写入串行、错误可观察。
