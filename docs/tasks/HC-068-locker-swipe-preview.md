[HC-069](HC-069-locker-controls-release.md) 接入正式页面后，实时原型共享新版更衣室结构。以下旧版布局以各阶段留存的截图为准。

- 暗色写实和玻璃外观均可预览，保留球员信息和球队操作。复用当前手势与示例数据，无持久化或 Android 改动。
- 使用 `node scripts/preview-appearance.mjs` 启动，打开 [滑动原型](http://127.0.0.1:4196/?locker=swipe)。

## 球员名片方案

[名片原型](http://127.0.0.1:4196/?locker=player-card) 沿用纯滑动交互，名片压成一行，只显示姓名和球衣号码。更衣室按钮改为「编辑球员」，面板标题为「编辑球员资料」。面板使用现有队员切换、昵称、号码、可选主角色和保存流程。通过两张竖屏效果图评审。

Chrome 390 × 844 实际打开更衣室并点开编辑面板，两张暗色效果图在 `artifacts/qa/hc068-player-card/`。

[无名片版](http://127.0.0.1:4196/?locker=no-player-card) 整块移除球衣下方的球员名片，保留滑动、位置圆点和底部操作，球员资料仍通过「编辑球员」查看和修改。

[三段排版原型](http://127.0.0.1:4196/?locker=layout) 在无名片版上压缩球队信息、放大竖屏柜体和球衣、让圆点贴近柜子，底部保留两项操作。写实和玻璃都可通过网页切换查看。

Chrome 390 × 844 分别截取两种外观，效果图在 `artifacts/qa/hc068-locker-layout/`。

[文字和按钮排版原型](http://127.0.0.1:4196/?locker=controls) 以无名片版为基础。球队名和状态分两行，去掉重复的「当前球队」。手机竖屏的「换球队」约 88 × 36 像素，底部两个按钮等宽，高 46 像素，字号 14 像素。

Chrome 390 × 844 的写实和玻璃截图在 `artifacts/qa/hc068-locker-controls/`。

本地入口返回 HTTP 200，Chrome 竖屏截图确认暗色卡片的圆点、球衣、球员信息和操作按钮可见，箭头、数字和提示已隐藏。未做 Android 验收。
