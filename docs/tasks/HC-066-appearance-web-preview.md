# HC-066 · 双外观网页预览

状态 `completed`（本地预览范围）。将用户讨论的玻璃与暗色写实方案接到可操作的网页预览。目标为按原布局比较外观，写实更衣室场景铺到主卡四边，球衣与原有控件叠在场景上。

- 复用正式页面、业务和动效。仅预览入口注入外观开关、写实素材和主题样式，不将预览打包进正式网页或 APK。
- 更衣室、训练场、我的的右上角切换全局外观。暗色适配战术库、球队、体型选择、球员配置及通用弹窗，区分主操作、次操作、选中、聚焦和禁用状态。
- 独立本地预览源使用示例数据。外观偏好仅在该预览源记忆，不访问正式浏览器或 APK 数据。
- 验收范围为打开预览、三页及代表性子页可达、切换主题保持当前页面、写实卡全铺且球衣和操作可见、玻璃保留原版布局。静态原型图随预览提供。

运行 `node scripts/preview-appearance.mjs`，打开 [交互页](http://127.0.0.1:4196/) 或 [效果图](http://127.0.0.1:4196/previews/appearance/concepts.html)。预览默认写实。三个主页面右上角都可切换。用示例 3v3、4v4 队伍体验原有交互，刷新重置示例资料，保留外观偏好。原页面及样式由 Vite 预览入口加载，主题及两张柜体照片仅从预览目录加载。

Edge 实际打开交互页，确认 390×844 下三页外观按钮可切换，队员切换从 1/3 到 2/3。查看战术库、体型、球员配置、球队管理，以及 1280×800、360×400 的写实更衣室。效果图页面 HTTP 200，两次记录均无页面脚本异常。截图留在 `artifacts/qa/hc066-appearance/`。未运行项目回归或 Android 验收。本地网页的独立审查及修复见 [HC-066 审查](../reviews/HC-066-appearance-web-preview.md)。
