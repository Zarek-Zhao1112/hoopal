# HC-063 · 通用角色与本队演练正式接入

状态 `awaiting_device`。1.30.0 已安装，真实 WebView 程序检查通过，用户的物理触摸和本队实际演练待体验。将用户确认的 [HC-062 原型](HC-062-team-role-preview.md) 接入正式版。3v3 用三个角色，4v4 用四个角色。允许重复与留空。球队按体型挑选战术，进攻按偏好一对一分配，支持临时交换，训练场使用实际队员号码。防守沿用内置示范。

通用角色按球员存入现有球队档案。旧数据无角色时兼容读取，旧战术角色记录不用于新分配。独立浏览沿用模板编号，换队不串用站位。包含正式入口验证、独立审查、Android 构建与指定手机覆盖安装。

主控拥有应用入口、工作区、版本与交付；`roles_data` 负责共享匹配和存储；`roles_picker` 负责阵容入口和玻璃面板；`roles_training` 负责训练场展示。目标版本 1.30.0 / code 36。

## 接口与数据边界

- 阵容继续使用 schema 2。可选球员字段 `mainRole` 只保存当前人数允许的角色。3v3 为持球发起、掩护策应、空间终结，4v4 为持球发起、掩护配合、接球策应、空间终结。留空省略字段。旧档案原文按现有迁移和损坏字段保护约定处理。
- 角色面板以球队 ID、版本和全队成员 ID 提交草稿。操作失败时可重试。未设置角色的队伍可照常观看示范。部分设置时按位置偏好优先匹配，余位按阵容顺序补齐。各位置唯一占一人。设置相同角色的球员可同时承担不同位置。
- 18 套进攻战术随构建校验站位偏好。按体型挑选的球队入口启用分配，防守或独立浏览使用内置编号。当前战术的手动换位只在内存中生效，恢复或重选重新计算。进度键仍只记录内置战术 ID 和步骤。
- 训练场映射号码、队员姓名、步骤与职责说明，保持动画棋子 ID、路线、球权与内置 JSON 导出兼容。PNG 对应当前可见球场。
