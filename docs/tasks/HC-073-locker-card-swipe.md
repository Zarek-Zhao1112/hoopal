# HC-073 · 整卡横滑正式接入

用户批准 [HC-072 原型](HC-072-locker-card-swipe-preview.md)。有球队的更衣室在写实与玻璃外观下均允许从整张卡片起滑，包括标题、球队信息、留白、圆点和按钮。横滑按原门槛每次切换一位，球衣跟手。纵滑保留浏览器滚动，轻点保留按钮原操作。滑完轻点编辑打开新选中球员。

正式更衣室把卡片传给现有轮播作为手势区域，原球衣视口继续负责动画和键盘交互。预览入口复用正式手势并使用示例球队。存储、战术和 Android 平台接口无变更。以轮播测试和两种外观的浏览器触摸模拟作为本次验收。

状态 `completed`（源码接入与浏览器验收）。254 项单元测试通过。Chrome 390 × 844 在两种外观下验证按钮、标题、球衣横滑、纵滑不换人，以及随后轻点进入 11 号单人编辑。连续注入极短的模拟手势时曾观察到浏览器未生成首次轻点的 click，按实际拖动时长模拟后两种外观均通过。未进行真机触摸或 APK 更新。
