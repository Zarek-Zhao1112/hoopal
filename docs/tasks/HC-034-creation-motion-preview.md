# HC-034 · 建队三步与大球衣动效预览

- 日期：2026-10-26；状态：`completed`（独立效果与动效预览）。
- 用户选择第三步「上方大球衣、下方配置标签」，要求效果图；本轮交付独立HTML/PNG与交互预览，不改正式1.19.0/存储/版本/APK/手机。
- 设计沿用[玻璃任务面板](../design/lineup-glass-sheet.md)与现有NBA资源，三步为建立球队、选择球队风格、球员入队。

## 视觉与交互

统一半透明冰川蓝玻璃壳，顶部任务进度、中间内容、底部固定按钮；背景是当前四栏档案页，打开时渐模糊变暗、玻璃面板450ms浮起。步骤1大队名输入+3v3/4v4人数卡；步骤2队徽浅弧横滑选择+真实对应球衣；步骤3上方大球衣/姓名号码、球员位置与完成状态，下方资料/体型/擅长/可选弱项。手机不整页滚动，短屏缩放、横屏左右分区；不虚构能力评分。

步骤前进内容向左轻移淡出、新内容从右进，返回反向，约320ms；壳/进度/底控稳定。球员同步横移约280ms，左拖下一位/右拖返回；资料与球衣始终同成员，取消手势不切换。已到达步骤可点回看，切换不丢输入；未配置成员可见。减少动态效果直接切换。

所有数据仅在内存；预览显著说明不会写入正式档案。完成只展示演示结果、不得说已保存到本机。可用query demo/step供三屏截图；默认从真实空白第一步体验，支持关闭/重新打开，关闭有改动提供继续/保留本次草稿/放弃。保留仅会话有效。
