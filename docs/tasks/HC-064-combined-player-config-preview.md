# HC-064 · 球员配置合并原型

状态 `completed`。基于 [HC-063](HC-063-team-role-release.md) 的通用角色规则，预览从更衣室和球队管理共用一个「配置球员」入口。

- 沿用上浮玻璃面板。点击名单切换当前队员，同一张卡内编辑昵称、球衣号码和可选角色。
- 3v3 保留三种通用角色，4v4 保留四种，均可重复选择或留空。换人保留草稿，底部一次保存。
- 使用预览中的样例队伍与内存草稿。正式版入口、档案格式、战术逻辑和 APK 不在本次范围内。
- 交付可点击网页和竖屏效果图。

入口为现有团队角色预览的 `view=players`，可用 `mode=3v3` 或 `mode=4v4`，加 `options=1` 进入时展开角色选项。Edge 导出两张 390 × 844 竖屏图，分别呈现 3v3 收起和 4v4 展开。4v4 样例中点选已有队友使用的角色、修改昵称、切换队员再返回并保存，草稿与更衣室显示符合预期，浏览器无脚本异常。
