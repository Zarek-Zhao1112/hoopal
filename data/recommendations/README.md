# 阵容推荐规则与验证边界

日期：2026-10-24，HC-008基础与HC-027扩展。规则在 [offense.js](./offense.js)，计算在 [../../shared/recommendations.js](../../shared/recommendations.js)。这是针对仓库现有十八套进攻动画的本地训练建议，不是专业认证、对手分析或得分预测。

## 官方资料与本项目推论

- [FIBA/WABC Level 1 教练手册](https://assets.fiba.basketball/image/upload/documents-corporate-wabc-coaching-level-manuals-level-1-eng.pdf)，2.1.1 Basic floor spacing / pass and cut / give and go、2.2.10 On-ball screens / dribbler options：支持传切配合、空间、持球者观察掩护后选择顺下或外弹等基础区分。
- [FIBA/WABC Level 3 教练手册](https://assets.fiba.basketball/image/upload/documents-corporate-wabc-coaching-manual-level-3-eng.pdf)，2.3.2 Screening angles and alignments：掩护者的释放可包含顺下、外弹或再次掩护，不能把所有挡拆都分配成篮下终结。
- [FIBA Tactics Board：Nizhny and Murcia](https://www.fiba.basketball/en/news/bcl-18-19-news-tactics-board-nizhny-and-murcia-double-double-overtime-trouble)：西班牙挡拆中的第三人为顺下者的防守人设背掩护后外弹，支持本仓库2号同时具有掩护和投射职责的解释。它是比赛案例，不是阵容评分标准。

把上述动作转换成六个自报技能标签、权重、复杂度及条件标记，是本项目的设计推论；官方资料没有认证此算法，也没有给出这些分数。实际角色号来自本仓库逐帧动画核对，可能不同于其他教练的同名战术。体型只在已标掩护或终结优势时作极小辅助，不凭身高、体格生成任何技能优势。

## 比较方式

仅取同人数内置进攻。按稳定成员ID排序后枚举3!或4!个一对一分工，同分保留稳定顺序；昵称、球衣号、队徽、主题色和输入排列均不参与能力比较。每个职责权重在 `weights`，必须确认的关键优势在 `essential`，有明显跑位负担的职责为 `moving`。

已选擅长计正向证据，明确弱项计负向证据，未选按一般。技能加权后按该配合总权重归一化，再扣关键优势缺口、复杂度和偏慢成员承担移动职责的负担。灵活只支持跑位衔接，不抵消技能弱项。强壮只对已具掩护优势、偏高只对已具终结优势各加0.3分，远小于技能变化。

关键优势未标、任一本职责所需技能明确弱项或移动职责偏慢，均显示为有条件备选。没有投射优势不等于不会投；投射明确弱项会单独提示冲突。排序最多返回三套不同配合，不输出内部分数或匹配百分比。每套说明完整列出当前分工的关键缺口、弱项冲突与移动负担；复杂配合额外提示先分段练时机。

## 独立审查案例

以下行为例由实现者测试并交给独立审查者判断篮球语义，不以断言公式权重代替审查：

1. 全一般、全同型灵活：优先基础条件练习，不声称强匹配或凭空技能优势。
2. 无投射优势与全员投射弱项分开；投射依赖配合不掩盖弱项或把一般说成不会投。
3. 唯一持球传球优势者加其余弱控球弱传球：映射仍一人一职，第二组织点缺口可见。
4. 高大强壮却弱掩护、弱终结者，与偏矮偏瘦但明确擅长掩护终结者：不得以体型替代技能。
5. 手递手：最适合突破控球者到2号；交球掩护接投者到1号。
6. 高低位：高位最强传球者到4号，最强终结者到3号；高个不自动成为高位终结者。
7. 西班牙挡拆：2号背掩护和外弹；4号主掩护顺下。连续双掩护的2号同时需注意接投和后续内传。
8. 全员偏慢：连续切入或突破负担明确，4v4会提高高低位这种较少移动职责的候选相对次序。
9. 改昵称、号码、主题、同名成员及交换输入顺序：保持排名与成员ID映射稳定，绝不合并同名成员。
10. 增加传球弱项：原承担组织的成员可被调整，排序或职责有实际变化，不能只换一句提示。

验收另检查同人数、无防守候选、最多三套、不重复、每个成员恰好一次、输入与原动画不变。真机流畅度和本地保存由集成与设备验收分别记录。
